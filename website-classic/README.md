# nadavfriedman.com · classic edition

The original Squarespace look (black ground, tan type, Cormorant Garamond and
Garamond, pill buttons, centred logo) rebuilt with a clearer flow that leads
with Nadav's current percussion work. Same structure and deploy steps as
`../website/` (see its README); build with `python3 website-classic/build.py`
and deploy `website-classic/public`.

Pages: Home · Live · Projects · About · Media · Study · Contact.
Concert dates: `public/assets/js/concerts.js` (shared format with ../website).
