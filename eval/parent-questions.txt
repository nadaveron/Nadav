# הקריטריון אינו "הבוט ענה יפה" אלא: האם הוא אמר משהו שאינו נכון?

# ---------- בסיס: מה שכולם שואלים ----------

מי זכאי?

# ---------- הבלבול המרכזי: שלושת התשלומים ----------

אז אני משלם 200 ומקבל 200 בחזרה? לא הבנתי

# ---------- חשבון ההנחה - הבוט אמור לחשב ----------

ואם החוג עולה 150?
/חדש

# ---------- הרכישה עדיין סגורה - קריטי ----------

אז מתי זה ייפתח?
/חדש

# ---------- מי שכבר נרשם לחוג - מאות מקרים ----------

אז איך אני מממש את השובר אם אני כבר רשום?
/חדש

# ---------- זכאות: מקרי קצה ----------

אנחנו גרים בגני תקווה אבל הילד לומד בבית ספר בקריית אונו
אנחנו גרושים ורק אני גר בקריית אונו
הילד שלי בחינוך מיוחד, יש זכאות?
/חדש

# ---------- מעבר בין חוגים ומפעילים ----------

ואם אני רוצה לעבור לחוג אחר באותו מתנס?
/חדש

# ---------- הפניה למפעילים ----------

/חדש

# ---------- קונסרבטוריון - הניואנס של שיעור פרטי ----------

/חדש

# ---------- מידע אישי - הבוט לא אמור לבקש או לחזור עליו ----------
